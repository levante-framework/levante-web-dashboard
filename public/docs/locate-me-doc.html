📍 Locate Me · GADM docs

Documentation for the polygon/region lookup flow that powers the map on the Locate Me page.

Data sources

  • GADM shapefiles: Zipped per country in gs://levante-assets-dev/maps, mapped in config/gadm-bucket-files.json.
  • Country whitelist: The ten approved countries appear in config/gadm-countries.json.
  • City geocoder: data/geocoder/cities.min.json(.gz) supplies the top-ranked name|admin1|country tuples driving polygon lookups.

Polygon API workflow

1. Download + cache

api/gadm-polygon.js downloads the country archive once, picks the most detailed shapefile (_3 or _2), reads every feature via shapefile, and populates:

  • bucketCache – raw features keyed by country code.
  • snippetCache – normalized name|admin1|country snapshots.

2. Exact snippet lookup

The handler attempts to match the normalized name (and its ASCII alias) with the snippet index before resorting to geometry scans. Matches return the polygon plus adminLevel, candidate count, and source: "snippet".

3. Fallback scan

If no snippet matches, it iterates the cached features and tests each with @turf/boolean-point-in-polygon, still preferring the most specific polygon (highest GID level and smallest area) and tagging the response source: "scan".

4. Caching

Both the raw features and snippet map stay in memory after the first download, so subsequent requests to that country are fast.

Snippet generation

Run this helper after downloading an updated extract:

node scripts/build-gadm-snippets.js \
  --input /path/to/gadm41_USA.geojson \
  --output public/data/gadm/snippets.json \
  --config config/gadm-countries.json
  • Normalizes name|admin1|country the same way the client does.
  • Groups every matching feature into a lightweight FeatureCollection.
  • Host those snippets directly if you prefer instead of serving the entire shapefiles.

Frontend hooks

  • public/js/locate-me-v2.js builds normalized keys, calls /api/gadm-polygon with name, ascii, admin1, lat, and lon, caches the JSON, and renders it with Leaflet.
  • The Documentation button now links here for quick reference.
  • scripts/apply-version.js rewrites the footer text and asset query strings prior to every deploy to avoid caching issues.
