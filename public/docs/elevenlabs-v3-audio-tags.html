ElevenLabs v3 Audio Tags: Simple User Guide

Put square brackets around short phrases in your text to add emotion, sounds, or style.

Works only with the v3 voice model.

How to Add Tags

  • Type your normal text.
  • Add tags anywhere: [excited] or [laughs].
Hi there [happy]! Isn't this fun [laughs]? Shh [whispers] it's a secret.

Common Tags to Try

Feelings
  • [happy] - Cheerful tone
  • [sad] - Down, slow
  • [excited] - Fast, energetic
  • [angry] - Loud, sharp
  • [calm] - Relaxed
Speaking Style
  • [whispers] - Very quiet
  • [shouts] - Loud
  • [pause] - Short break
  • [rushed] - Quick talking
Fun Sounds
  • [laughs] - Adds laughter
  • [sighs] - Tired breath
  • [gasp] - Surprised inhale

Quick Tips

  • Tags last 4-5 words, then fade.
  • Mix them: [excited][laughs].
  • Make up your own like [pirate voice] - v3 understands many.

Tip: Keep tags short and test in small edits to hear the difference quickly.
